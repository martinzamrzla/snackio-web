# snackio-web

Web společnosti Snackio Solutions s.r.o. — https://snackiosolutions.cz

- `index.html` — celý web v jednom souboru (HTML, CSS, JS i logo vložené jako data URI).
- `netlify.toml` — nastavení nasazení na Netlify (statický web, bez build kroku).

## Nasazení

Repozitář je napojený na Netlify. Každý push do větve `main` se automaticky nasadí na snackiosolutions.cz.
